# Development record

These nine documents are scrubbed copies of the design records from the
private campaign repository where bunnyforge was first built, frozen at
the 2026-08 public cut (each carries a provenance header). They are kept
as the tool's design history, not as living documentation.

Known limitations, accepted at the cut:

- References to pull-request numbers, branches, tags, and implementation
  plan files point into the private repository and cannot be resolved
  from here.
- Cross-references to other specs by `docs/superpowers/specs/…` path
  resolve normally — the copies live at exactly those paths.

Future bunnyforge design documents are born in this directory.
