# Templates

Copy these; do not edit them in place.

```sh
cp _Templates/npc.md NPCs/vessarine-holt.md
```

Each template opens with the shared agent contract explaining the front-matter
fields. The `summary` field in the front matter is the highest-leverage line in
any file — it is written to be retrievable on its own, so it should name the
entity, its role, and its current status without relying on pronouns or context.

Section comments are instructions, not decoration. Leave them in place while a
file is incomplete; they tell an agent what belongs in an empty section, which
is the difference between the agent asking you a question and the agent
inventing an answer.
