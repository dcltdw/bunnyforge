# Open Questions

Deliberately undecided things. This file exists so an agent knows the difference
between a fact it has not found and a fact that does not yet exist.

Format: the question, why it is open, and what constrains the eventual answer.
When a question is answered, delete it from here and write the answer into the
file that owns it.

Undecided *world and design* questions belong here. Deferred *workspace and
tooling* work belongs in `[[tickets]]`.
