# Tickets

Deferred **workspace, tooling, and process** work — the things that do not fit
`[[open-questions]]`, which is for undecided *world and design* questions.

Keep this file even if you track the work somewhere else (an issue tracker, a
board). AGENTS.md links to `[[tickets]]`, and a wikilink with nothing behind it
is a checkup warning; a one-line pointer to wherever the real tickets live is
enough to satisfy it.
